# API Reference

Base URL (local dev): `http://localhost:8000`

Interactive docs are auto-generated by FastAPI and available at `/docs`
(Swagger UI) and `/redoc` once the backend is running.

## Auth
| Method | Path | Description |
|---|---|---|
| POST | `/api/v1/auth/register` | Create a new account |
| POST | `/api/v1/auth/login` | Get a JWT access token |
| GET | `/api/v1/auth/me` | Get the current authenticated user |

All other endpoints below require `Authorization: Bearer <token>`.
