# User Guide

1. **Register / Log in** — create an account to unlock all features.
2. **Dashboard** — see your scores and recent activity at a glance.
3. **Chat Coach** — free-form chat with your AI interview & communication coach.
4. **Communication Check** — paste text to get grammar corrections and a fluency score.
5. **Vocabulary** — get stronger, more professional word/phrase alternatives.
6. **Resume Analyzer** — upload a resume file for strengths, improvements, and a score.
7. **Mock Interview** — pick a role and difficulty, answer a generated question, and get scored feedback.
8. **Progress** — track your scores over time.
9. **Profile / Settings** — manage your account and preferences.

If an AI provider is temporarily unavailable, InterviewIQ automatically
falls back to the next configured provider, and ultimately to an
offline knowledge base, so the app keeps working.
